# 临界 · 紧急调度 v2.2.0（CITY EMERGENCY DISPATCH）

一款在浏览器里直接运行的城市应急调度游戏。你是织雾市 911 指挥中心的值班长：接警、判断、派车、盯住倒计时。城市、乡下、工业区、监狱、机场、火车站都在同一张地图上，单人生涯、无尽值班或六位编号联机合作。

> 线上入口（部署后）：<https://zhiwumansui.pages.dev/emergency/>
>
> 技术栈：原生 HTML / CSS / JavaScript + Canvas 2D + WebAudio；无构建步骤、无后端依赖。联机使用 PeerJS 公共信令 + WebRTC P2P。图形、建筑、车辆、火焰与音效均由代码实时生成，没有外部图片/音频素材。

---

## 一、怎么开始

### 电脑
1. 打开上面的网址（或直接打开 `emergency/index.html`）。
2. 点「生涯模式」→ 阅读行动简报 → 开始值班。
3. 鼠标拖动地图，滚轮缩放；点击警情卡片查看需求；点「派遣」或「一键派遣」。

### 手机 / 平板
- 同一网址，横竖屏均可。单指拖动地图，双指缩放；点底部「警情 / 单位 / 调度台」打开面板。
- 直接用浏览器打开即可，横竖屏均可；不提供安装或离线模式。

### 本地直接打开
双击 `emergency/index.html` 即可（`file://`），单机功能完整；联机会自动跳过/受限。若浏览器限制本地文件，起一个静态服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/emergency/
```

## 二、模式

| 模式 | 内容 | 存档 |
| --- | --- | --- |
| 生涯模式 | 五个班次：风雨夜 → 工业区警报 → 白岩之夜 → 机场惊雷 → 临界时刻。每班结束进入补给站购买增援/升级。 | 自动保存班次、资金、升级 |
| 无尽值班 | 没有交班时间，波次逐渐变密、变强，冲击本机最高分。 | 只保存最高分/排行榜 |

失败条件：声望降到 0，或单班伤亡超过上限。生涯失败可以重试本班，已购买的升级保留。

## 三、玩法要点

- **接警 → 派遣 → 到场 → 覆盖处置**。警情卡片写着需要的能力（警力 / 灭火 / 医疗 / 危化 / 救援）。
- 只有单位**到场且能力覆盖需求**，处置进度才会推进；缺一种能力，倒计时不会停，只会被“部分覆盖”减速。
- 单位返回基地后要**整备**，短时间内不能再次出动。轮换使用比一次梭哈更稳。
- 火警处置太慢会**蔓延**到附近建筑；交班后不再新增蔓延。
- 优先处理 P1（红色）与窗口短的警情；P3 可以稍后。不要用云梯车去处理小盗窃。
- 「一键派遣」是兜底：自动挑选最近、最能补齐缺口的待命单位。手动搭配通常更快。

### 特殊地点
- **中心城区**：住宅、写字楼、商场、学校、医院，警情最密。
- **织雾工业区**：化工厂、储罐、仓库、厂房，危化与储罐火灾。
- **稻香乡**：农舍、谷仓、农田、乡卫生院，距离远、道路窄。
- **白岩监狱**：监区冲突、监狱暴动，需要足够警力。
- **织雾国际机场**：航站楼、跑道、机库，可疑行李、跑道异物、飞机失事、航班紧急迫降。
- **织雾站（火车站）**：列车脱轨、车站踩踏；铁路从城市与工业区之间穿过。
- **地铁站 / 公交总站 / 公交站台**：地铁踩踏与火灾、公交站台事故、公交站冲突；城区主路上有多个公交站台标记。
- **环城高速**：地图北缘的封闭高速，三条匝道接入城区/工业区；高速车祸只在这条路上生成，地图上有“环城高速”路牌。
- **中央政府区**：中央人民政府、最高人民警察局、最高人民消防局、最高人民医院、最高人民法院、最高人民检察院、监察委员会；贪污腐败等调查类警情落在这里。
- **织雾山**：山林、湖泊、盘山公路与隧道；山火、溺水、隧道坍塌。
- **织雾湾**：沙滩、海面、码头、跨江/跨湖桥；鲨鱼、洪涝、海啸、台风、桥梁倾斜。
- **加油站 / 航空油料库**：3 座地面加油站让附近返场的**地面单位**整备加快；**直升机只能在所属单位/基地整备补给**，不能使用外部加油站或航空油料库。
- **新增警情**：飞机失事、越狱、持械逃窜、酒驾肇事、肇事逃逸、人员失踪、银行/超市劫案、列车脱轨、车站/地铁踩踏、公交车事故、山火、溺水、鲨鱼、盗警车/警用直升机/直升机/飞机、隧道坍塌、高架/大桥倾斜、贪污腐败、争吵、洪涝、海啸、龙卷风、台风、雷击、漏电、跳楼、校园欺凌、车祸、高速车祸、化学品泄漏车祸等；原有抢劫、监狱冲突、化工厂爆炸等保留。
- **建筑级随机任务**：住宅、商铺、工厂、学校、车站、码头等每一类建筑都会按类别抽任务，不再只有固定 50 多条警情。
- **现实模拟表**：选中任一警情，右侧会显示现场平民/工人/旅客/嫌疑人以及每个单位正在做什么；追逐、酒驾检测会实时更新。

### 单位
巡逻车、特警装甲车、高速追捕车、应急指挥车、工程抢险车、泵浦消防车、云梯消防车、森林消防车、危化救援车、救护车、急救摩托、医疗直升机、消防直升机、警用直升机、水上救援艇。每个单位的能力值可在游戏内调度台查看。警用直升机也可被盗窃，会触发空中追捕。

> 地图从 140×100 扩到 **220×160**，共 8 个区域；这是 2D 调度地图，不是 1:1 城市测绘。

## 四、操作与设置

| 操作 | 说明 |
| --- | --- |
| 拖动地图 / WASD / 方向键 | 平移视角 |
| 滚轮 / 双指捏合 | 缩放地图 |
| 点击警情卡片或地图标记 | 查看需求、派遣 |
| 点击待命单位 | 查看详情；先选警情再点单位可直接派遣 |
| 一键派遣 | 自动补齐当前警情的能力缺口 |
| 空格 | 暂停 / 继续 |
| 1 / 2 / 3 | 1× / 2× / 4× 时间 |
| F | 看全图 |
| H | 玩法说明 |
| Esc | 暂停菜单 / 关闭弹层 |

设置包含：画质预设、渲染缩放、粒子、天气效果、画面震动、帧率上限、扫描线、地名标签、减少动态、色弱辅助、主音量/音乐/音效/环境、静音、开局速度、边缘拖屏、大事件自动暂停。**难度固定为「真实」**，不再提供轻松/标准/硬核选择。

- 画质设置会实时影响渲染（低画质关闭灯光/减少粒子/降低输出分辨率；220×160 底图固定 0.5x，切换画质不会重建底图，避免卡顿）。
- 修改设置会立即保存到本机；联机中加入者的时间与暂停由房主控制。
- 音频在第一次点击/触摸后才启动；切到后台会自动压低。**没有持续警笛**，只在派遣/到场时给短提示音。
- 暂停时车流、雨、粒子、警灯与镜头震动全部冻结；城市时钟按班次加速，昼夜光照与时钟同步。

## 五、战绩、成就与排行榜（本机）

- 主菜单 →「成就与排行榜」：三个标签页分别是战绩、成就、本机排行榜。
- 战绩：生涯完成班次、总积分、处置成功/失败、伤亡、无尽最佳、联机次数、累计成功处置。
- 12 个成就：第一次接警、零伤亡交班、S 级、滴水不漏、生涯通关、撑过第五班、无尽 5000 分、联机合作、一键派遣 10 次、危化 3 起、40 秒响应、采购 5 项。
- 排行榜保存每次行动的积分（生涯单班 / 无尽 / 联机），按分数保留 **本机 Top 10**。
- **只存在当前浏览器 localStorage，不上传、不跨设备同步**；清除站点数据会一并清空。
- 若需要真正的全服排行榜，需要额外的后端/数据库（当前版本没有做）。

## 六、联机合作

1. 主菜单 →「联机合作」→ 创建房间；把显示的六位编号发给队友。
2. 队友在同一网址输入编号 + 呼号加入。
3. 房主点「开始联合行动」。难度固定真实；双方进入同一张地图，警情、时间、分数共享。
4. 房主主持时间与模拟；加入者的派遣/撤离/一键派遣会作为指令发送给房主执行。
5. 最多 4 人；共享指挥权，没有语音/文字聊天（现场沟通建议另开语音）。

**限制与注意**
- PeerJS 公共信令服务器 + WebRTC 直连，不需要自建服务器；但需要网络允许 WebRTC。公司/校园/严格 NAT 网络可能无法连接。
- 房主必须保持页面可见（浏览器会暂停后台标签页的动画循环）；房主关闭页面或断网，行动结束。
- 房间编号只是临时房间名，不要用于传输敏感信息。
- 联机成绩只记录在各自设备的排行榜。

## 七、安装与离线（已移除）

- 本版本**不再提供 PWA / 安装提示 / 离线缓存**；页面只走普通网页加载。
- 旧版本留下的 Service Worker 会被 `sw.js`（清理器）自动注销并删除旧缓存；如果仍看到旧画面，刷新两次或在浏览器站点设置里清除缓存。
- 回退：删除 `sw.js` 即可；游戏本体不依赖它。

## 九、部署（Cloudflare Pages / 静态站）

游戏是 `emergency/` 独立静态目录，不需要 Functions 或 D1：

1. 把 `emergency/` 提交到仓库（随站点一起部署）。
2. Cloudflare Pages 构建命令留空，输出目录 `.`（与站点现有配置一致）。
3. 部署后确认：
   - `/emergency/` 返回 200；
   - `/emergency/sw.js` 返回 200（仅用于清理旧缓存）；
4. 首页已加入口卡片：`index.html` → `content-grid` 里的「临界 · 紧急调度」。

## 十一、已知限制 / 未验证

- 这是 **2D 调度管理**，不是《消防模拟》那种 3D 物理救援；没有第一人称、车辆物理、真实水枪/破拆操作。
- 山火、海啸、台风、龙卷风、隧道坍塌等是**调度事件**（时间窗口、能力需求、伤亡/损失结算），不是流体/建筑物理模拟；画面只有地图标记与天气氛围。
- 加油站是**地面单位**的整备加成点（返场冷却缩短），不是逐车油量模拟；**直升机只能在所属单位/基地整备**，不能使用外部油站或航空油料库。
- 单位 AI 会在追车时选择尾随、前方路口设伏或 PIT；酒驾被拦停后会先吹气，可能配合被捕，也可能突然再次逃跑。
- 现场平民/工人/伤员是**行为模拟标记 + 行为记录**，不是逐个 3D 人物寻路。
- 难度固定为「真实」，不再提供难度选择；旧存档会自动迁移。
- 排行榜是**本机**的，没有全服排行；成就也是本机的。
- 联机没有聊天/语音/观战；房主关闭页面会结束行动；严格 NAT 下可能连不上。
- 暂无英文界面；界面为简体中文。
- 主要在 Windows Edge/Chromium 上自动化验证；Firefox/Safari 未做完整回归。移动端按 390×844 验证，其他尺寸可能有个别排版差异。
- 数值平衡是人工调的，存在“某类警情偏难/偏易”的可能，欢迎反馈。

## 十二、回退办法

- **只撤游戏入口**：删除根目录 `index.html` 里 `content-grid` 中「临界 · 紧急调度」那段 `<a class="card">`。
- **撤整个游戏**：删除 `emergency/` 目录（不影响站点其它页面）；如果已部署，等一次 Pages 部署。
- **撤 PWA**：见第七节。
- **代码回滚**：`git revert <本次提交>` 或 `git checkout <旧提交> -- emergency index.html`。
- 游戏不修改站点 `functions/`、`data/`、数据库或其它页面，删除目录即可完全恢复。
