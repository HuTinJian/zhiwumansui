发现问题，直接上报

页面打不开、按钮没反应、排版错位、内容写错……任何站点问题都欢迎。 越具体越好：在哪个页面、点什么会触发、你看到的是什么。

  • 页面异常
  • 样式错位
  • 内容有误
  • 体验问题

发送问题反馈

带 *星号 的是必填项；问题描述最多 1000 字。

0 / 20

不超过 20 字；不填也可以，站长不会追问。

0 / 1000

写清「哪个页面 + 什么设备/浏览器 + 怎么复现」最有用；最多 1000 字。

0 / 60

只用来回复你，不会公开展示；不超过 60 字。

提交即表示同意本站按 隐私说明 保存以上内容； 入库前会剔除 < > 字符。请勿填写身份证号、住址等敏感信息。

01 怎么写更有用

  1. 哪个页面：首页 / 宝库 / 鸣谢 / 法律，或直接贴页面地址。
  2. 什么环境：手机还是电脑、什么浏览器、大概什么时候出现。
  3. 怎么复现：点了哪个按钮、看到了什么、能不能稳定重现。
  4. 有截图更好：把图片链接写进「联系方式」，或直接发邮件。
