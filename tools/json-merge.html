📦 JSON 合并工具

把 D1 里的新歌合并到主数据 roblox_music.json

📖 操作步骤（第一次用请按顺序做）
  1. 导出 D1 新歌：后台 → 🎶 歌曲管理 → 点右上角 📤 导出，会下载 songs_extra_xxx.json。
  2. 上传原有数据：点第一个方框，选中你网站文件夹里的 data/roblox_music.json。
  3. 上传新歌数据：点第二个方框，选中刚下载的 songs_extra_xxx.json。
  4. 点合并：点中间的 🔀 合并，看统计结果。
  5. 下载：点 💾 下载合并后的 JSON，得到新的 roblox_music.json。
  6. 替换并重新部署：用新文件覆盖 data/roblox_music.json，重新上传网站到 Cloudflare。
  7. 最后清空 D1：后台 → 🎶 歌曲管理 → 点 🧹 清空。
