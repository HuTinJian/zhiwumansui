➕ 添加歌曲

📖 支持哪些写法（认不出来时再点开看） 每行一首，怎么排都行（自己会认）：
· 晴天 1876950732 或 晴天1876950732（中间没空格也认）
· 1876950732 晴天 或 1876950732《晴天》（ID 在前也行）
· 晴天：1876950732 / 晴天-1876950732 / 晴天、1876950732 （冒号、顿号、破折号、竖线这些夹在中间的东西都会清掉）
· 《晴天》1876950732、"晴天" 1876950732（书名号、引号、括号、emoji 自动清掉）
· 晴天 【古风国风】1876950732 或 分类：古风国风 晴天 1876950732（手动指定分类，优先级最高）
· 《海浪》（中文摇滚）95728570379323（括号里直接写分类，也能认）
· 一行多组串在一起也行：难绷电音笑99474474122230 飞起来！112064181015623
· 歌名一行、ID 另一行分开贴也能配上对；一行多个 ID 会作为"同名多 ID"一起加
· 分类不用自己写：认不出来时按关键词 + 中/英/日文自动归到站内那 14 个分类里
· ID 必须是 9 位及以上的纯数字

➕ 添加隔离歌曲

两种贴法都行：
· JSON 数组：[{"id":"xxx","name":"歌名","category":"分类"}]
· 或者直接贴「歌名 + ID」的多行文本（跟「➕ 添加歌曲」一样自己认 ID、自己判断分类）
